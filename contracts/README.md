# Veil contracts

The registry targets BNB Smart Chain and uses native BNB or a standard BEP-20 token for rewards and hunter stakes. It verifies Groth16 proofs through the `IGroth16Verifier` interface (generated by snarkjs from the Circom circuit).

## Local test

Run Foundry:

```powershell
cd contracts
forge test -vv
```

## BSC Testnet deployment

Copy `.env.example` to `.env`, supply the deployer key, then run:

```powershell
cd contracts
forge script script/DeployTestnet.s.sol:DeployTestnet `
  --rpc-url $env:BSC_TESTNET_RPC_URL `
  --broadcast --legacy
```

For production deployment with the real Groth16Verifier (after running `node zk/scripts/setup.mjs`):

```powershell
$env:GROTH16_VERIFIER="0x<deployed Groth16Verifier address>"
forge script script/Deploy.s.sol:Deploy `
  --rpc-url $env:BSC_TESTNET_RPC_URL `
  --broadcast --legacy
```
