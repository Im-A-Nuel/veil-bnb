# Veil BNB

Veil is a private bug-bounty protocol for BNB Smart Chain. A hunter can prove an exploit with a RISC Zero receipt, receive the escrowed reward on-chain, and reveal the actual exploit privately to the bounty creator.

This repository is being rebuilt as a monorepo for the Indonesia Web3 Hackathon 2026:

- `apps/web` — the Veil Next.js interface.
- `apps/agent` — AI-assisted guest drafting and prover service.
- `contracts` — Solidity contracts and Foundry tests.
- `zk` — RISC Zero guest and host programs.
- `scripts` — local development helpers.
- `docs` — architecture and deployment notes.

The working local setup and BSC Testnet deployment guide will be added as each implementation stage lands.
